# AI Scam Trend Analyzer 🔍🤖

AI Scam Trend Analyzer is a full-stack AI-powered web application that detects, analyzes, and tracks scam messages using Machine Learning and real-time analytics.

## 🚀 Features
- Scam message detection using AI
- Scam category prediction
- Risk score analysis
- OCR-based text extraction
- Real-time analytics dashboard
- Scam trend monitoring
- User authentication system

## 🛠️ Tech Stack

### Frontend
- React.js
- Vite
- Tailwind CSS
- Axios
- Recharts

### Backend
- Node.js
- Express.js
- MongoDB Atlas
- JWT Authentication

### AI/ML
- Python
- Flask
- Scikit-learn
- TF-IDF
- Logistic Regression
- Tesseract OCR
